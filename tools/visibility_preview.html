What the model guarantees

target contrast = 1 + weight × (foreground contrast - 1). The build solves the provider alpha first, then the face opacity needed for each preset. The same source supplies the stroke and text sizes. Reference floors guard against accidental extra dimming.

Other colors retain the calibrated alphas. Some combinations cannot reach the reference floors even with opaque foreground. Anti-aliasing, scaling, overlapping marks and the decimal backdrop alter individual pixels. Screen brightness, outdoor light and eyesight still require watch testing.
