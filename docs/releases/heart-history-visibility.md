# Binary Heart History 0.3.1-prototype

- Increase trace contrast in Faint, Subtle, and Clear and thicken the line while keeping the area fill faint
- Keep time marks brighter than the trace and optional timestamps brighter than the marks
- Move the graph farther below the binary clock while preserving the system-indicator reserve
- Retain visible isolated readings, missing-data gaps, and saved settings

This update uses Binary Heart History's Wear OS internal testing track. The installed Binary Pulse face receives the updated graph from the history provider and does not need a replacement face package. The graph remains hidden in AOD, independently of the numeric heart-rate setting.
