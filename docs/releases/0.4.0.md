Binary 0.4.0 adds native heart rate and makes room for Wear OS activity indicators while keeping the binary time centered and prominent.

## Changes

- Show native heart rate beside battery, with decimal, hexadecimal, and binary readouts
- Place both readouts above the lower complications
- Reserve bottom-center space for the notification dot and ongoing-activity indicator
- Balance the two-, three-, and four-complication layouts while preserving complication assignments
- Keep the established time position and size

The layout was verified on a physical Pixel Watch with a running stopwatch in active and always-on modes. Automated clearance checks guard the reserved area against future regressions.

## Install

Join the [tester group](https://groups.google.com/g/binary-watch-face-testers), then [opt in to the Google Play closed beta](https://play.google.com/apps/testing/dev.j256.binarywatchface) for Play-managed installation and updates. The Play update becomes available after Google approves it.

For manual installation, download `binary-watch-face.apk` and `binary-watch-face.apk.sha256` below. This universal APK was exported from Google Play and carries its app-signing certificate.

```sh
shasum -a 256 -c binary-watch-face.apk.sha256
adb install -r binary-watch-face.apk
```

Install on the watch. See the [installation guide](https://github.com/j-256/binary-watch-face#install) for Wi-Fi setup and replacing a locally signed debug build.

Requires Wear OS 7 (API level 37) and Watch Face Format 5. This is a beta release; GitHub publication does not enroll downloaders as Play testers.
